# Mikke MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a dependency-free, mobile-first Mikke vertical slice where users create natural-language Watches, confirm parsed conditions, run shopping checks, and see meaningful matches.

**Architecture:** Keep Watch parsing, evaluation, event derivation, and provider connectors as framework-independent ES modules. The first slice uses localStorage and a deterministic sample shopping connector so the full interaction works without credentials; later Rakuten/Yahoo and server persistence reuse the same domain interfaces.

**Tech Stack:** Browser ES modules, Node built-in test runner, HTML/CSS, localStorage.

**Spec:** `docs/superpowers/specs/2026-09-29-universal-watch-design.md`

## Global Constraints
- Free-first; no required metered AI API.
- Prefer official APIs and permitted data sources.
- iPhone is the primary UX target.
- Avoid unnecessary repeated external requests.
- Product behavior must not block on routine user confirmation.
