# Universal Product Conditions and Trigger Engine

Date: 2026-09-29
Status: **Superseded**

This design has been replaced by:

`docs/superpowers/specs/2026-09-29-domain-specific-watch-conditions-design.md`

Reason: the original design made product attributes too generic and did not model domain-specific conditions deeply enough, especially for flights, hotels, and other non-shopping Watches. The replacement keeps a shared Watch core and common trigger engine while moving condition definitions into rich domain-specific schemas.

The previous version remains available in Git history for reference and must not be used as the implementation source of truth.
